# Project rules

`AGENTS.md` (repo root) is authoritative. `CLAUDE.md` (repo root) contains the
GSD-specific non-negotiables — read both before starting.

Short version: every branch, commit and PR starts with the Linear ticket id
`LMG-<n>`; never commit to `main`; never merge automatically; never use a phase
number as a commit scope (`feat(01-02)` is forbidden).
