<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Acceslibre dump -> database | External open data becomes rows; a malformed row must not corrupt the referential |
| HTTP search -> PostGIS | User-supplied lat/lng/q/filters reach SQLAlchemy; must stay parameter-bound |
| Public API -> third parties | Untrusted consumers; rate-limit and no writes |
## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Injection | search/import | high | mitigate | SQLAlchemy parameter binding only; no raw SQL from user input. |
| T-03-02 | Tampering | dedup/merge | high | mitigate | Soft merge only + `place_merge_log`; never delete; a bad merge is reversible by `canonical_id`. |
| T-03-03 | Information disclosure | import errors | medium | mitigate | Errors echo the domain message, never the DB URL or raw row. |
| T-03-04 | DoS | public search | medium | mitigate | Mandatory radius/limit + rate limiting (Phase 7); bounded `ST_DWithin`. |
| T-03-SC | Tampering | new dependencies | high | mitigate | Prefer stdlib `difflib`; if `rapidfuzz` is added, review and pin in `uv.lock`. |
</threat_model>
