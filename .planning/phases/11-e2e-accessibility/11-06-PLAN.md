<task type="auto">
  <name>Task 3: the `check:i18n` literal-aware regression guard</name>
  <files>web/scripts/check-i18n.mjs, web/package.json</files>
  <precondition>Tasks 1–2 and plans 11-01/11-05 are all landed, so every literal has moved and the guard can pass on the final tree.</precondition>
  <action>
Add `web/scripts/check-i18n.mjs`: a Node script (using the already-present `typescript` compiler API —
`ts.createSourceFile` + a recursive AST walk — no new dependency) that collects **every string literal
wherever it appears** in the scanned files: JSX text nodes, string literals inside JSX expressions
such as `{loading ? "Résultats" : …}` and `{place.category ?? "Catégorie inconnue"}`, AND ordinary
string literals in call/argument positions such as `setGeoMessage("Localisation refusée …")` and
`.catch(() => "Recherche indisponible.")`. The old "JSX text nodes + display attributes only" read is
gone — the French in this codebase lives in expression and call positions, so a guard that reads only
JSX text proves nothing.

1. Builds a file list by walking, relative to `web/`: `src/components/search/**`,
   `src/components/record/**`, `src/components/auth/**`, `src/components/account/**`,
   `src/app/(auth)/**`, `src/app/account/**`, and the single files `src/app/page.tsx`,
   `src/app/places/[slug]/page.tsx`, `src/app/places/[slug]/not-found.tsx`,
   `src/components/site-header.tsx`, `src/components/locale-switch.tsx`. Exclude any path matching
   `*.test.*` or `*.spec.*`. Never scan `src/lib/i18n.ts` (it is the authoritative fr source).
2. For each file collect string literals (`ts.isStringLiteral`, `ts.isNoSubstitutionTemplateLiteral`)
   in **any** position, then exclude these non-display positions: the value of a JSX attribute or
   object property named `href`, `className`, `id`, `key`, `value`, `type`, `role`, `name`,
   `htmlFor`, or any name matching `data-*`; and the whole `metadata`/`generateMetadata` export
   declaration (its `title`/`description` are SEO/brand, not interface chrome). Text nodes,
   expression literals, call arguments, and `aria-label`/`placeholder`/`alt`/`title`/`aria-valuetext`
   values are all scanned.
3. Flags a collected literal if it contains an accented French character in
   `àâäéèêëîïôöùûüçœæÀÂÄÉÈÊËÎÏÔÖÙÛÜÇŒÆ` OR any token (case-insensitive, substring match) from the
   denylist (`Rechercher, Recherche, Résultats, Chargement, Autour de, Localisation, Aucun, lieu,
   Doublon, Catégorie, Enregistrer, Publier, Anonyme, Précédent, Suivant, avis, Note, Photos,
   Accessibilité, Compléter, Source non, Non renseigné, Se connecter, Connectez-vous, Mot de passe,
   Créer un compte, Mon compte, Se déconnecter, Réinitialiser, Voir plus, Vérifiez`). On any hit,
   exit 1 listing `file:line` per hit; otherwise exit 0 with a one-line summary of files scanned.

Because `#avis` sits in an `href` (an excluded attribute) and the test files are excluded, the `#avis`
href is not flagged — state this in a code comment in the script.

Wire it into `web/package.json`: add `"check:i18n": "node scripts/check-i18n.mjs"` and change the
`"lint"` script to `"eslint . && node scripts/check-i18n.mjs"` so the guard runs wherever lint runs.
