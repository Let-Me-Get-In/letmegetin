# Phase 4 Plan — Record & Reviews (read)

**Ticket:** LET-9 · **Requirements:** PLACE-03, PLACE-04, REV-01
**Depends on:** Phase 3 (PR #6) — the plan assumes the place model, `get_place`,
`PlaceAccessibilityModel`, `category_grid` and the Acceslibre importer are on `main`.

## Task 1 — Acceslibre writes `place_accessibility` + `filled_rate`

**Why:** PLACE-04 needs values; Phase 3 shipped the table with no writer.

**Files**
- `src/letmegetin/domain/places/acceslibre_map.py` (new): `FIELD_MAP` of Acceslibre export keys
  → `(criterion_slug, value_builder)`. Only keys we can map confidently; everything else ignored.
- `src/letmegetin/domain/places/repositories.py`: add
  `PlaceRepository.replace_accessibility(place_id, values)` (delete + insert or upsert).
- `src/letmegetin/infrastructure/persistence/repositories.py`: implement it.
- `src/letmegetin/application/places/import_acceslibre.py`: capture the mapped keys in
  `AcceslibreRow.accessibility`, write them on create **and** on re-import of an existing
  `(source, source_id)` (today re-import is skipped; values must still refresh).
- `src/letmegetin/application/places/get_place.py`: compute `filled_rate` against the category
  grid criteria; return the grid tree with values merged.
- `src/letmegetin/api/schemas/places.py`: `PlaceDetailOut.tree`, `filled_rate`.

**Steps**
1. Write the mapping table + unit tests for one unknown key (ignored) and one known key.
2. Extend the row parser; keep `_to_row` total (no exceptions on odd payloads).
3. Upsert accessibility on import; add an integration test asserting a second import updates
   values without creating a place.
4. `filled_rate` = `filled / total_in_grid`, rounded 3; `0.0` when the grid is empty.
5. Detail response: `tree` = grid nodes with `value` injected per criterion; flat `accessibility`
   kept for compatibility.

**Verify:** `uv run pytest tests/unit/test_places_dedup.py tests/integration/test_places_import.py -q`;
importing the fixture twice leaves one place and refreshes values.

## Task 2 — Reviews read path (REV-01)

**Files**
- `migrations/versions/0004_reviews_photos.py` (new): `review` table.
- `src/letmegetin/infrastructure/persistence/models.py`: `ReviewModel`.
- `src/letmegetin/domain/places/entities.py` + `repositories.py`: `Review`, `list_reviews`,
  `review_stats`.
- `src/letmegetin/application/places/list_reviews.py` (new).
- `src/letmegetin/api/v1/places.py` + `schemas/places.py`: `GET /places/{slug}/reviews`,
  `rating`/`review_count` on the detail.

**Steps**
1. Migration: `review(id, place_id FK cascade, rating smallint check 1..5, body text,
   author_name, status default 'published', created, updated)` + index `(place_id, created desc)`.
2. Read endpoint: `page`/`size` validation, `{items,total,page,size}`, 404 on unknown slug,
   hidden reviews excluded.
3. Detail: `rating` = avg (1 decimal, `null` when none), `review_count` (published only).
4. Tests: pagination boundaries (page 2, size 1), empty set, 404, hidden excluded.

**Verify:** `uv run pytest tests/integration/test_places_reviews.py -q`.

## Task 3 — Photos + complete record (PLACE-03)

**Files**
- Migration `0004`: `place_photo(id, place_id FK cascade, url, credit, license)`.
- `PlaceModel`/`PlaceDetailOut`: `photos: list[PhotoOut]`.
- Importer: read `photos` from the export when present (URL + credit + license); nothing else.

**Steps**
1. Import photos idempotently (same URL not duplicated).
2. Detail returns address, category, `rating`, `review_count`, `photos`, `tree`, `filled_rate`,
   `accessibility_by_family`.
3. End-to-end test: import fixture → detail + reviews + photos in one call.

**Verify:** full suite green; `alembic upgrade head` on a clean PostGIS database.

## Done when

1. A place detail returns the accessibility tree with values and a `filled_rate`.
2. Reviews are paginated and readable; the detail carries the average rating.
3. Photos come from the source, never invented; empty list when absent.
4. Full suite green and coverage floor respected.
