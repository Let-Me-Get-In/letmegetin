## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Elevation of privilege | src/letmegetin/admin.py | medium | accept | The CLI is local-only and gated by the database credentials in the environment; no HTTP surface is added and Phase 5 adds role checks. Documented in README. |
| T-02-02 | Tampering | application/referential/admin.py write use cases | high | mitigate | All writes go through SQLAlchemy parameter binding; slugs pass through slugify and the models enforce varchar bounds; no raw SQL string is built from user input. |
| T-02-03 | Tampering | criteria.is_default and category_criteria.excluded | high | mitigate | The mapping resolves in one repository method, and the unit test asserts an exclusion survives a re-seed, so a default cannot silently overwrite an operator override. |
| T-02-04 | Information disclosure | migrations/env.py and CLI output | medium | mitigate | Errors echo the domain message only; the CLI never prints settings.database_url and the integration test asserts the message contains no SQL. |
| T-02-05 | Denial of service | unlink / edit commands | low | accept | No delete command ships in this phase, so no cascade can remove categories or criteria; a wrong edit is corrected by the next edit. |
| T-02-06 | Tampering | migrations/versions/0002 | medium | mitigate | The 0002 table and columns mirror models.py column for column, and the downgrade path is verified before merge. |
| T-02-SC | Tampering | uv add typer | high | mitigate | Package legitimacy gate: typer is the FastAPI maintainers' CLI library, pinned by a minimum version, resolved through uv.lock, and reviewed on PyPI before the lockfile is committed. |
