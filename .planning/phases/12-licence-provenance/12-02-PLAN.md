<objective>
Prove the provenance write → read → API path end-to-end for one real place and one answer: an
Acceslibre import and a user contribution both stamp provenance, and `GET /api/v1/places/{slug}`
returns `source`, `license` and `observed_at` on the place and on every answer. This is the tracer
slice of the phase — it proves the schema (12-01) through the write path and the public contract on
one vertical path, before the admin surface (12-03), the enforcement predicate (12-04) and the
conflict rules (12-05) expand out from it.

one commit, not after the later layers are built. The source → licence resolution lives in the
repository against the reviewed `source_licence` table, so no importer or contribution code carries a
licence literal (LIC-05, D-07).

Output: the `upsert_accessibility` signature + repository resolution, both callers passing provenance
explicitly, the detail endpoint surfacing provenance, and the public contract (`docs/public-api.md`
+ regenerated `docs/openapi.json`).
