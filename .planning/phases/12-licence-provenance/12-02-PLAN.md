<objective>
Turn the licence catalogue into a reviewed, auditable data surface with an operator CLI: the
`admin licences sync|matrix|audit` group mirrors the existing `families` commands, so adding or
changing a destination is a git-reviewed CSV change, never a code change (LIC-05). This plan
completes D-05/D-06/D-08 beyond 12-01's minimal loader.

Purpose: make licence rules a data review — the phase's core promise (LIC-05) — with an exit-1
audit gate so a gap or an unknown licence cannot slip through.

Output: `licences.py` audit/matrix use cases, the `admin licences` typer group, a `LicenceRepository`
port + SQLAlchemy implementation, and unit + functional tests mirroring the families lineage.
</objective>

| Boundary | Description |
|----------|-------------|
| Reviewed CSV → `licence`/`licence_destination` tables | A git-reviewed data file is the source of truth; an erroneous row would silently widen or narrow the redistribution rule. |
| Operator CLI → DB | Trusted operator, but `destination`/`licence_slug` strings from the CSV must stay in a closed set. |
