<objective>
Deliver the enforcement predicate that Phases 14-17 call: a pure `domain/` function
`can_redistribute(licence, destination)` plus its SQL twin (`JOIN licence_destination`) for bulk
extraction, so no exit path re-implements the redistribution rule. This is LIC-02/LIC-03 made into
one reviewed rule (D-13) with fail-closed behaviour (D-15) and exclude-and-count semantics (D-14),
surfaced to the operator through an `admin licences excluded` command. Scope note: the D-14 exclusion
counts delivered in this phase are the `admin licences excluded` output only — the import-report
counters and the Phase 14 output manifest are out of Phase 12 scope and are not modified here.

Purpose: give the export (14) and feed (15-17) work a single, callable, tested rule so they never
hand-roll a redistribution check — and prove LIC-03 (`odbl` × `lov2_partner` = false) from the data,
while giving the operator a way to answer "what did we leave out, and why" without reading code.

Output: `domain/places/licence.py` (pure predicate), the SQL twin + exclusion manifest in the
repository, an `admin licences excluded` command, a unit test for the predicate, and a functional
test proving the domain predicate and SQL twin agree and the manifest lists excluded ids.
</objective>
