<objective>
Implement the conflict and freshness rules on the shared write path: ownership by current source
(D-09), same-source freshness on `observed_at` (D-10, with every NULL combination explicit),
insert-if-absent across sources (D-11), and the append-only write journal (D-12). This is LIC-04 read
literally — a later re-import can never overwrite a fresher contribution or a row that came from
another source.

Purpose: the federation phases (15-17) will re-import sources; this plan makes "re-import never
clobbers a human's work" a data rule enforced in one place, not a promise each importer must keep.

Output: the `upsert_accessibility` rewrite (ownership check + freshness compare + insert-if-absent +
journal append), and a functional test proving the conflict matrix including all four NULL
combinations.
</objective>
