<objective>
Lay the provenance data model and the reviewed licence data, and backfill every existing row so
that no place or answer is left with a NULL licence (LIC-01, D-04). The source → licence mapping is
a new reviewed CSV (`source_licences.csv`) plus a `source_licence` table, so the same correspondence
that this plan's backfill applies is also the one the write path (12-02) and the admin sync (12-03)
resolve at write time — satisfying LIC-05 (rule in reviewed data, never importer code) and D-07
(effective date on the correspondence).

Purpose: prove the schema gate and the backfill first, on the agent's best early-context tokens.
The columns, the four new tables and the reviewed mapping are the phase's load-bearing seams; the
write path (12-02), the admin surface (12-03), the enforcement predicate (12-04) and the conflict
rules (12-05) all expand from them without architectural change.

Output: migration `0011`, extended models/entities/mappers, the three reviewed CSVs, and a
functional test proving the backfill leaves zero NULL licences for every existing source.
</objective>
