`osm_version` and full raw `osm_tags`) flows out as one `.osmChange` `<modify>` element that carries

`osm publish` use case + CLI, proves the non-destructive `<modify>` contract (BLOCKER 1: emit
`stored tags ∪ our accessibility tags`, refuse and count any object whose stored tag set is absent),
and defines the D-10 throttle constant — so a dead-end in the write-back shape or the destructive-
modify risk is caught after one slice, before the policy artefacts (16-05) are built on top.

Output: a pure `.osmChange` serialiser, a minimal `osm publish` + gate (ToS flag + artefact
presence), an `OSM_THROTTLE_SECONDS` constant, and one functional round-trip test proving a place
flows DB → `.osmChange` element with its full tag set.
