    fail-closed applies only to a malformed AUTHORED row (empty field, duplicate `(osm_key, osm_value)`
    key, or wrong header -> DomainError); a tag the review chose not to map is an absent row, not an
    error, and never raises. Do NOT

    question 2), shaped on families.py load_families + lov2_export.py _read_csv:
    `load_osm_accessibility_tags(path) -> dict[tuple[str, str], tuple[str, str]]` reading
    `osm_key;osm_value;criterion_slug;criterion_value` with csv.DictReader(delimiter=";"). Fail
    closed: exact header `("osm_key","osm_value","criterion_slug","criterion_value")`, a duplicate
    `(osm_key, osm_value)` key or an empty field raises DomainError. It returns
    `{(osm_key, osm_value): (criterion_slug, criterion_value)}`. The criterion-slug / typed-value

    loader stays dependency-free.
