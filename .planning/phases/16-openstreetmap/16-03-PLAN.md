<objective>
Wire the already-shipped Phase-3 dedup scorer into the OSM importer so an OSM POI that already
exists as an AccesLibre place becomes a linked row (canonical_id, alias, merge log) rather than a
duplicate, and surface the D-06 unmatched-tag-combination report so the operator sees exactly which
OSM tags the category mapping is missing.

Purpose: this is the "dedup + report" expansion. The tracer proved a new place imports; this plan
makes the import behave like the AccesLibre one against a populated table — source-agnostic dedup,
nothing deleted — and turns the skip-and-count branch into a readable growth mechanism for the
category mapping.

Output: a fully wired `import osm` (dedup + `--no-dedup` + `--dry-run`) and a one-screen report with
the top unmatched tag combinations.
</objective>
