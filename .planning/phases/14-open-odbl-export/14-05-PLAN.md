      one-off container writing the shared volume, D-12).

      "$OUT" --delta` — the MVCC-boundary delta. The watermark is read and advanced INSIDE the export
      command under its own flock (D-10); the wrapper does NOT read latest.json with jq and does NOT pass
      --since.
    - any other value: print `usage: export-odbl.sh {snapshot|delta}` to stderr and exit 2.
    No secret is baked in; the systemd units and the Actions workflow invoke it through
    scripts/with-secrets.sh (D-12). The `-T` is mandatory for the systemd/SSH contexts.

    runs `bash scripts/export-odbl.sh <mode>` with a PATH shimmed to a FAKE `docker` (a shell shim that
    records its argv to a temp file); assert BOTH modes (F7 — the wrapper argv test must exercise the
    delta branch, not only snapshot, so the undefined-$OUT bug would fail under `set -u`):
    - `snapshot` builds and runs exactly `docker compose … run --rm -T -v export_data:/data/export api
      letmegetin-admin export odbl --out /data/export` (no --delta; `-T` and `-v export_data:/data/export`
      present — B1);
    - `delta` runs the SAME command with `--delta` appended and the SAME `--out /data/export` and the SAME
      `-v export_data:/data/export` override, and the fake docker's recorded argv contains NO `--since`
      and NO `cat`/`jq` (the watermark is inside the export command, D-10); both modes use the ONE `OUT`
      variable — no undefined reference under `set -euo pipefail`;
    - an unknown mode exits 2 and prints the usage line.

    `bash -u` so an undefined variable in either branch fails the test.
