database holds — in the same transaction as the write — then expose the per-place history read
(D-13) that proves the journal is usable.

migration, repository) → CLI for the one capability every later export task depends on (the
journal is the replay source for D-09/D-10 and the history surface for D-13), so the journal
contract is proven before the ZIP assembly and the serving layer build on it.

Output: the `export_event` table migrated, append hooks at every place-write choke point, and a working
`letmegetin-admin place history <slug>` command.
