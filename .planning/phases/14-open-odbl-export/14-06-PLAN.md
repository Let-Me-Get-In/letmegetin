<objective>
Make the AccesLibre import chunk-committed and resumable so a national load respects the
per-transaction event cap (EXPORT_MAX_EVENTS_PER_TXN) the delta-overlap window depends on, and an
interrupted run is repaired by re-running it.

Purpose: D-16 (reviewed) — the import keeps the per-transaction cap but is now chunked and idempotent
by (source, source_id), so it reports how far it got instead of pretending all-or-nothing. This is the
import half of the F3 invariant 14-01 enforces on the repository side: the repository asserts a single
append batch never exceeds the cap, and this plan guarantees a single import transaction never appends
more than the cap.

Output: a chunk-committing import loop that reports committed-chunk progress, plus a functional test
proving resumability and the chunk boundary.
</objective>
